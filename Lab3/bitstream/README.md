# DMA tutorial overlay

Lab3 uses the existing PYNQ-Z2 DMA tutorial overlay from:

```text
https://github.com/onigas/PYNQ_Workshop/tree/master/Session_4/bitstream
```

Required files:

```text
dma_tutorial.bit
dma_tutorial.hwh
```

The Lab3 notebooks download these files automatically when they are not present and Internet access is available.

For offline laboratory use, copy both files into this directory before starting Lab3.2.
